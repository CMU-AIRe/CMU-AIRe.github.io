# AIRe Lab website

The website of the AIRe Lab (Artificial Intelligence and Reinforcement Learning) at Carnegie Mellon University, served by GitHub Pages at https://cmu-aire.github.io/.

## Updating the site

The pages are plain HTML generated by one Python script (no installs needed; Python 3.9+).

1. Edit the sources in `site-src/`:
   - **People, news, page text:** `site-src/build.py` (the `MEMBERS`, `COLLABORATORS` and `NEWS` lists near the top).
   - **Publications:** `site-src/papers/<year>.json`, one entry per paper.
   - **Paper figures:** put the image in `media/papers/` and list it in `site-src/manifest.json`.
   - **Headshots:** a square image in `media/people/`, named as in `MEMBERS`.
2. Rebuild: `python3 site-src/build.py`
3. Preview: `python3 -m http.server` from the repository root, then open http://localhost:8000/
4. Commit both the sources and the regenerated pages.

## Layout

- `index.html`, `people.html`, `publications.html`, `join.html`: generated pages (don't edit by hand).
- `style.css`, `home.js` (home page people/paper linking), `swarm.js` (the learning swarm on the home page): hand-written.
- `gridworld.js`, `post.js`: kept for later (an earlier home page demo, and the archived blog).
- `pages/`: redirects from the old site's addresses.
- `images/`: original, full-size photos and the logo source.
